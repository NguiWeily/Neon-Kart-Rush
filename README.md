# Neon Kart Rush

An original, lightweight Android arcade kart racer with a neon/cyber visual style. The road, scenery, rivals, pickups, particles, HUD, and kart graphics are all drawn procedurally at runtime — there are no copyrighted characters or third-party art assets bundled in the project.

## Highlights

- Fast pseudo-3D neon highway rendering using the Android Canvas API
- Landscape full-screen gameplay
- Touch steering with left/right controls
- Rechargeable nitro boost
- Five AI rival karts
- Three-lap race format
- Coin pickups and turbo pickups
- Off-road slowdown, collisions, screen shake, glow and particle effects
- Countdown, timer, speedometer, lap counter and finish screen
- No ads, analytics, login, tracking or network permission
- No external runtime libraries

## Controls

- Left side: steer left
- Right side: steer right
- BOOST button: hold for nitro
- Tap the title screen to start
- Tap after finishing to race again

## Requirements

- Android 6.0 / API 23 or newer
- Android Studio with Android SDK 35, or GitHub Actions
- JDK 17

## Build in Android Studio

1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select an Android device or emulator.
4. Run the `app` configuration.

To make an APK from Android Studio, use **Build > Build APK(s)**.

## Build from the command line

This project uses Android Gradle Plugin 8.7.3. With Gradle 8.9 and Android SDK 35 installed:

```bash
gradle :app:assembleDebug
```

APK output:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Browser demo / GitHub Pages

A standalone browser version is included in `docs/index.html` and `demo/index.html`. Open it directly in Chrome, or enable GitHub Pages with the `/docs` folder as the source to get a public playable link for sharing.

Keyboard controls in the browser demo: **Left/Right arrows** to steer, **Space** for boost, **Enter** to start. Touch controls work on phones.

## Build automatically on GitHub

A workflow is included at `.github/workflows/build-apk.yml`.

1. Create a GitHub repository.
2. Upload/push this project to the repository.
3. Open the repository's **Actions** tab.
4. Select **Build Android APK**.
5. Open the completed run and download the `NeonKartRush-debug-apk` artifact.

The workflow also runs automatically whenever code is pushed to `main` or `master`.

## Install the APK

Copy `app-debug.apk` to the Android phone, open it, and allow installation from that source if Android asks. For local developer installs, you can also use:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
