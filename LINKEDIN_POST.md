# LinkedIn post

I challenged ChatGPT to create a playable Android kart racing game from a single prompt — not just a concept or code snippet, but a complete project.

The result: **Neon Kart Rush**.

It includes a procedural pseudo-3D track, neon graphics, touch steering, boost, AI rivals, pickups, particles, lap timing and a GitHub Actions workflow that can build the APK automatically.

The interesting part is that the visual assets are generated at runtime with code, so the project does not depend on copyrighted kart-game characters or external art packs.

Built with ChatGPT using GPT-5.6 Sol.
